## What I Do

- **Full-Stack Application Development:** Building interactive, responsive frontend interfaces and secure, performant REST APIs using React/Next.js and Node.js/NestJS.
- **Application Containerization:** Packaging application codebases into optimized, multi-stage Docker containers configured for dev, staging, and production environments.
- **Kubernetes & Cloud Orchestration:** Managing application lifecycles, configuration, and deployments on Amazon EKS using Helm, Kubernetes manifests, and Ingress controllers.
- **Infrastructure as Code (IaC):** Automated provisioning and lifecycle management of AWS resources (VPC, EC2, RDS, S3, IAM) using modular, declarative Terraform scripts.
- **Continuous Integration & Delivery:** Designing and optimizing pipelines using GitHub Actions, Jenkins, and AWS-native CI/CD tools (CodePipeline, CodeBuild, CodeDeploy) for zero-downtime releases.
